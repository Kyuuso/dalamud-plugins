# Kyuuso Dalamud Plugins Repository

Custom repository of plugins for FFXIV / Dalamud.

## How to add this repository in Dalamud

1. In game, type `/xlsettings` in chat to open Dalamud settings.
2. Navigate to the **Experimental** tab.
3. In the **Custom Plugin Repositories** section, paste the following URL into the text box:
   ```text
   https://raw.githubusercontent.com/Kyuuso/dalamud-plugins/main/pluginmaster.json
   ```
4. Click the `+` button to add it, then click **Save and Close**.
5. Open the plugin installer with `/xlplugins`.
6. Search for **Eureka Aggro** in the list and click **Install**.

## Available Plugins

- **Eureka Aggro**: Complete aggro radar and danger visualizer for Eureka with support for sound (sleeping dragons), blood, magic, and proximity.
