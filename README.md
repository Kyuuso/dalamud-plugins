# Kyuuso Dalamud Plugins Repository

Repositorio personalizado de plugins para FFXIV / Dalamud.

## Cómo añadir esta fuente en Dalamud

1. Abre el juego y escribe `/xlsettings` en el chat (o abre los ajustes de Dalamud).
2. Ve a la pestaña **Experimental**.
3. En la sección **Custom Plugin Repositories**, añade la siguiente URL en el campo de texto:
   ```text
   https://raw.githubusercontent.com/Kyuuso/dalamud-plugins/main/pluginmaster.json
   ```
4. Haz clic en el botón `+` para añadirla y luego haz clic en **Save and Close**.
5. Abre el instalador de plugins con `/xlplugins`.
6. Busca **Eureka Aggro** en la lista e instálalo normalmente. ¡Ya no necesitas dev plugins!

## Plugins disponibles

- **Eureka Aggro**: Radar y conos de visión/aggro en Eureka con soporte para sonido (dragones), sangre, magia y proximidad.
